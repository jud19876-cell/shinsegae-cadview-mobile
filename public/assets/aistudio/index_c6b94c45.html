스마트폰 설치 & 개인용 무료 배포

방법 1. 단일 파일(.html)로 다운받아 폰에서 바로 쓰기 가장 간편

아래 버튼을 눌러 완성된 index.html 파일을 받은 뒤 카카오톡(나와의 채팅)이나 구글 드라이브로 내 폰에 보내고 크롬으로 열면 바로 작동합니다.

방법 2. 내 개인 주소로 무료 배포 & 설치용 APK 만들기 🔑 토큰 발급 ↗

GitHub 토큰(ghp_...)을 입력하고 배포를 누르면 나만의 전용 웹 앱 주소(https://아이디.github.io/my-cad-viewer/)가 자동 개설됩니다.

  • 홈 화면 앱(PWA) 설치: 생성된 주소를 안드로이드 크롬에서 열고 메뉴(⋮) → [앱 설치]를 누르면 실제 앱 아이콘이 생성됩니다.
  • 설치용 .APK 파일 추출: 생성된 주소를 PWABuilder.com에 붙여넣고 [Package for store → Android → Download APK]를 누르면 1분 만에 순정 .apk 설치 파일이 만들어집니다.
⚠️ GitHub Personal Access Token(ghp_...)을 입력해 주세요.
